# Problem Statement

An AI-powered Chrome Extension that detects phishing websites using the OpenAI API.

PhishGuard AI analyzes a website's URL and webpage content, sends the information to an AI backend, and provides users with a phishing risk score, confidence level, and detailed explanation.


## Features

- AI-powered phishing website detection
- Chrome Extension (Manifest V3)
- FastAPI backend
- OpenAI API integration
- Risk Score (0–100)
- Confidence Score
- Human-readable explanations
- Modern popup interface
- Real-time website analysis
